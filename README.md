# Estate & Co. Real Estate Website

A responsive static real estate website built with semantic HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. No build step or package installation is needed. Google Fonts and property photography load from public URLs and require an internet connection.

## Interactions

- Responsive mobile navigation
- Property search by buy/rent intent, neighborhood, and maximum price
- Neighborhood cards that filter listings
- Save and unsave buttons
- Property inquiry shortcuts that prefill the contact message
- Front-end inquiry confirmation state

The inquiry form is a demo. Connect it to a form endpoint or CRM to receive submissions.
